# Portal Studio 横向图标工具栏 v5 — 设计与执行摘要

## 已确认的最终方向

展开状态不是纵向面板，而是一条可拖拽的横向图标栏：

```text
[拖动] | [单选] [多选] [框选] | [复制] [显示标注] | [快捷键] [批注列表] | [折叠]
```

其中：

- 倒数第二个功能图标是“快捷键说明”；
- 最后一个功能图标是“批注列表”；
- 折叠箭头属于工具栏外壳控制，放在分隔线之后，不算功能图标；
- 每个可操作图标悬停或键盘聚焦时，都显示“作用 + 快捷键”；
- 批注列表和快捷键说明分别打开独立浮层，不把内容堆进工具栏；
- 工具栏始终保持一行，不恢复纵向大面板。

## 折叠状态

```text
[拖动] [批注图标或未完成数量] [批注工具] [展开]
```

- 没有未完成批注时显示批注图标；
- 有未完成批注时用数字替代图标，最高显示 99+；
- 不再使用 Wrench、Pencil、Emoji 或额外角标；
- 默认进入页面时折叠；
- 拖动位置保留；
- 折叠不能清空批注、任务或未保存文字。

## 快捷键

- Pick：macOS `⌘⌥P`；Windows/Linux `Ctrl+Alt+P`
- Multi：`⌘⌥M` / `Ctrl+Alt+M`
- Area：`⌘⌥A` / `Ctrl+Alt+A`
- Copy：`⌘⌥C` / `Ctrl+Alt+C`
- Marker 显示：`⌘⌥V` / `Ctrl+Alt+V`
- 批注列表：`⌘⌥L` / `Ctrl+Alt+L`
- 展开/折叠：`⌘⌥K` / `Ctrl+Alt+K`
- 快捷键说明：`?`
- 取消：`Esc`

输入框、文本域、contenteditable 和输入法组合期间不得触发。

## 任务执行

优先执行 Goal 01。它会一次性完成可见的横向工具栏闭环：

1. 横向折叠/展开外壳；
2. 正确图标和顺序；
3. Hover/Focus Tooltip；
4. 快捷键说明浮层；
5. 批注列表浮层；
6. Marker 全局显示改成纯展示状态；
7. 删除旧 Wrench、角标和纵向混合面板路径。

Goal 01 完成并独立复核后，再执行连续标注、Marker 稳定性、Agent CLI
和最终重构测试。
